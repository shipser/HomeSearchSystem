# 🏡 מערכת צ'ק-ליסט בדיקת דירות לקנייה - מערכת דינמית מרובת-מכשירים

מערכת מלאה ודינמית לניהול, עריכה ומעקב אחר בדיקות דירות יד שנייה לפני קנייה.
המערכת כוללת שרת **Node.js + Express**, מסד נתונים **SQLite**, וסנכרון בזמן אמת (**Real-time SSE**) לעריכה חלקה במקביל ממספר מכשירים (מחשב, סמארטפון וטאבלט).

---

## ✨ מה כוללת המערכת?

1. **מסד נתונים מרכזי (SQLite)**:
   - כל הדירות, השדות, הבדיקות, ההערות והתמונות/קישורים נשמרים בקובץ מסד נתונים `data/apartments.db`.
   - אין תלות ב-`localStorage` של דפדפן בודד - המידע משותף ונגיש מכל מכשיר.

2. **עריכה וסנכרון רב-מכשירי (Multi-Device Sync)**:
   - **התחברות מהירה מהנייד באמצעות קוד QR**: כפתור ייעודי בסרגל העליון מציג קוד QR לסריקה ישירה ממצלמת הסמארטפון.
   - **סנכרון בזמן אמת (SSE)**: שינויים שנשמרים בטלפון במהלך סיור בדירה מתעדכנים ישירות במסך המחשב בבית ללא צורך בריענון ידני.
   - **מחוון סטטוס סנכרון חי**:
     - 🟢 **מחובר ומסונכרן**: כל השינויים שמורים במסד הנתונים.
     - 🟡 **שומר שינויים...**: שמירה אוטומטית שקטה ברקע בזמן ההקלדה (Debounce).
     - 🔴 **שמירה מקומית (אופליין)**: במקרה של ניתוק רשת בדירה, המידע נשמר במכשיר ומסונכרן אוטומטית עם חידוש החיבור.

3. **סרגל ניהול דירות מתקדם**:
   - בחירה ומעבר מהיר בין דירות שמורות מתוך תפריט נפתח.
   - **חלון "כל הדירות"**: חיפוש וסינון מהיר לפי כתובת, מחיר, חדרים, הערות ומתווך.
   - **מסננים מהירים**: מעבר בקליק בין דירות רלוונטיות לכל הדירות, וסינון תלת-מצבי לפי תיווך (כולם / עם מתווך / ללא מתווך).
   - **שכפול טופס בקליק**: מאפשר ליצור עותק מהיר של דירה דומה באותו בניין או אזור.
   - **ייצוא גיבוי**: הורדת כל הנתונים לקובץ JSON לשמירה מקומית.

4. **📎 צירוף וניהול קבצים ומסמכים (File Attachments)**:
   - העלאת קבצים ישירות לכל דירה בסיום הטופס (אחרי שדה ההערות).
   - **סוגי קבצים נתמכים**: תמונות (JPG, PNG, GIF, WebP, SVG, BMP), מסמכי Word (`.doc`, `.docx`), מסמכי PDF וקבצי טקסט (`.txt`).
   - **מגבלות**: עד 20 קבצים במקביל לכל דירה, עד 20MB לכל קובץ.
   - **תצוגה מקדימה**: תצוגה מקדימה מוקטנת (עד 100x100 פיקסלים) עבור תמונות, ואייקונים ייעודיים לכל סוג מסמך.
   - **הורדה ומחיקה**: כפתור הורדה ישיר וכפתור מחיקה מהיר לכל קובץ.
   - **אחסון קבוע**: הקבצים נשמרים בתיקייה ייעודית `data/files/<apt_id>/` המשויכת אוטומטית לדירה.

5. **100% שימור של כל שדות הטופס המקורי**:
   - פרטים כלליים, אנשי קשר, קישור למודעה, מחיר, תאריכי פינוי, שטחים.
   - חדרים, מעליות, מרפסות דינמיות מרובות (גודל וכיוונים לכל מרפסת).
   - תשתיות מלאות: מים, איטום, צנרת, גז, חשמל, לוח, שקעים, תאורה.
   - מיזוג, מטבח, חדרי רחצה, שירותים, ריצוף, דלתות, חלונות, תריסים.
   - סביבה, חניה, מחסן, מדרגות, תחבורה, מוסדות חינוך, עומסים, עלויות קבועות (ארנונה, ועד, גז) והערות.

6. **התאמה מושלמת למובייל והדפסה נקייה**:
   - ממשק רספונסיבי מלא בעברית (RTL).
   - עיצוב ייעודי להדפסה (`@media print`): הדפסת דוח בדיקה נקי ומסודר או שמירה כ-PDF בלחיצה על כפתור ההדפסה.

2. בסרגל העליון של המערכת במחשב, לחץ על הכפתור **"📱 סרוק לנייד"**.

> 💡 **טיפ לסיור בדירות מחוץ לבית:**

## 🐳 הפעלה באמצעות Docker & Docker Compose

המערכת מוכנה להפעלה מיידית כקונטיינר Docker מבודד, מאובטח וקל משקל (מבוסס Alpine Linux).

### 1. הפעלה מהירה עם Docker Compose (Image חדש):
התלות החדשה (`multer`) מוגדרת ב-`package.json` ותותקן אוטומטית בעת הבנייה:
```bash
docker compose up -d --build
```
האפליקציה תיבנה ותרוץ ברקע בכתובת `http://localhost:3000`.

### 2. בניית Image והרצה ידנית:
```bash
# בניית ה-Image
docker build -t apartment-checklist .

# הרצת הקונטיינר עם שמירה של מסד הנתונים והקבצים המצורפים ב-Volume מקומי
docker run -d \
  --name apartment-checklist \
  -p 3000:3000 \
  -v "$(pwd)/data:/app/data" \
  --restart unless-stopped \
  apartment-checklist
```

### 3. עדכון קונטיינר / Image קיים (שדרוג לגרסה עם העלאת קבצים):

אם כבר רץ אצלך קונטיינר קיים ואתה מעוניין להוסיף את תכונת העלאת הקבצים ותלות ה-`multer`:

#### אפשרות א': בנייה מחדש נקייה (מומלץ ביותר — ללא איבוד נתונים)
כל הנתונים (מסד הנתונים וקבצים מצורפים) שמורים בתיקיית `./data` במחשב/שרת המארח, ולכן בנייה מחדש של ה-Image **לא פוגעת בנתונים כלל**:
```bash
# 1. עצירת הקונטיינר הקיים
docker compose down

# 2. בנייה מחדש נקייה והפעלה ברקע
docker compose up -d --build

# 3. בדיקת יומן ריצה לווידוא שהשרת עלה בהצלחה
docker compose logs -f
```

#### אפשרות ב': עדכון ישיר בתוך קונטיינר קיים (ללא בנייה מחדש)
אם אינך רוצה לבנות מחדש את ה-Image, תוכל להתקין את התלות החדשה ישירות בתוך הקונטיינר הפעיל:
```bash
# 1. התקנת חבילת multer בתוך הקונטיינר (כהרשאת root)
docker exec -u 0 -it apartment-checklist npm install multer --save

# 2. העתקת קבצי הקוד המעודכנים לתוך הקונטיינר
docker cp server.js apartment-checklist:/app/server.js
docker cp public apartment-checklist:/app/public

# 3. הפעלה מחדש של הקונטיינר
docker restart apartment-checklist
```

### ⚙️ הגדרות הרשאות וקונפיגורציה ב-Docker עבור העלאת קבצים

1. **אחסון קבוע של קבצים (Persistence)**:
   - הקבצים המועלים נשמרים בנתיב המכולה `/app/data/files/<apt_id>/`.
   - מכיוון שהתיקייה המארחת `./data` כבר ממופה לנתיב `/app/data`, **כל הקבצים נשמרים ישירות על הדיסק של השרת המארח** בתיקייה `./data/files/`.

2. **הרשאות כתיבה ב-Linux (Permissions)**:
   - הקונטיינר רץ תחת משתמש אבטחה לא מיוחס בשם `node` (UID `1000`).
   - בשרתי Linux, וודא שלמשתמש זה יש הרשאות כתיבה לתיקיית `data`:
     ```bash
     sudo chown -R 1000:1000 ./data
     sudo chmod -R 775 ./data
     ```

3. **הגבלות העלאה (Upload Limits)**:
   - גודל מקסימלי לקובץ: **20MB**.
   - מספר קבצים מקסימלי לדירה: **עד 20 קבצים במקביל**.
   - סוגי קבצים נתמכים: תמונות (`image/*`), מסמכי Word (`.doc`, `.docx`), מסמכי PDF וקובצי טקסט (`.txt`).

## 🛡️ הגדרת Reverse Proxy (Nginx) עם תמיכה ב-SSE ו-SSL

אם ברצונך לחבר דומיין עם תעודת SSL חינמית (Let's Encrypt), להלן קובץ קונפיגורציה מומלץ ל-Nginx התומך בסנכרון ה-Realtime (SSE):

```nginx
server {
    server_name apartments.yourdomain.com;

    # תמיכה בהעלאת קבצים ומסמכים גדולים (עד 20MB לכל קובץ)
    client_max_body_size 25M;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        # העברת כותרות זיהוי לקוח ודומיין
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # חיוני עבור סנכרון בזמן אמת (SSE - Server-Sent Events)
        proxy_set_header Connection '';
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 86400s;
    }
}
```

להפעלת SSL עם Certbot:
```bash
sudo certbot --nginx -d apartments.yourdomain.com
```

## 🔒 שמירה על נתונים וגיבויים

- **שמירת מסד הנתונים והקבצים ב-Docker**: תיקיית `./data` על השרת המארח ממופה אל `/app/data` בתוך הקונטיינר. כל הנתונים, מסד הנתונים (`apartments.db`) וכל הקבצים והמסמכים המצורפים (`files/`) נשמרים תמיד גם בעת עדכון, בנייה מחדש או אתחול של הקונטיינר.
- כל שינוי בטופס נשמר אוטומטית שקטה ברקע בזמן ההקלדה.
- תחת חלון **"כל הדירות"**, תוכל להוריד בכל עת קובץ גיבוי מלא של כל הדירות בלחיצה על **"גיבוי JSON"**.
